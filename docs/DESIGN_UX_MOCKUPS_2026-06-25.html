Design & UX mockups — proposed direction

Before / after for the three key screens, illustrating the review's main moves: one unified brand, AA-contrast labels, icons on web, calmer typography (less ALL-CAPS), a de-duplicated dashboard, and a clearer mobile action hierarchy. "Before" panes approximate the current build; "after" panes show the recommendation. Colours are the app's own palette.

Ocean (primary) Sun (warning only) Paper (surface) Ink (text)

2 · Operator dashboard — calmer, scannable, no echoes (D6–D8)

The current dashboard repeats the "needs attention" count three times and uses no icons with heavy ALL-CAPS labels. The fix: one attention hero, icons per metric, sentence-case labels, AA-contrast text, color reserved for real signal.
